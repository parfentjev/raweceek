## Project Overview

Rawe Ceek is a small web service that exposes upcoming racing sessions through an HTTP API and serves a lightweight static website. Keep the implementation small and the dependency count minimal; prefer the Go standard library when it is sufficient.

## Technical Stack

- HTTP server and routing: `net/http`
- Static assets: embedded HTML, CSS, JavaScript, and images
- API contract: OpenAPI with models and handlers generated by `oapi-codegen`
- Database: PostgreSQL using `pgx`, with queries generated by `sqlc`
- Logging: `log/slog`
